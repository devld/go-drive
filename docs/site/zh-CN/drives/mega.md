# MEGA Drive

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| 邮箱 | MEGA 账号邮箱 | 必填 |
| 密码 | MEGA 账号密码 | 必填 |
| 根目录 | 云盘中的文件夹；留空使用云盘根目录 | 云盘根目录 |
| 永久删除 | 删除文件时永久删除，不勾选则移到 MEGA 回收站 | 不勾选 |
| HTTPS 传输 | 对已经加密的文件传输使用 HTTPS | 关闭 |

go-drive 挂载账号的云盘，不显示收件箱、回收站和收到的共享。文件和文件夹名称在本地解密。上传、下载和复制都会经过 go-drive，因为 MEGA 在客户端加密文件内容。同一 Drive 内的移动和重命名使用 MEGA 的移动与属性命令。

MEGA 允许同一文件夹里存在多个同名节点。go-drive 保留修改时间最新的节点，并隐藏其余节点。名称中含有 `/` 或 `\` 的条目也会被隐藏，因为它们无法表示成单个路径片段。

双重验证只在 MEGA 账号开启了它时才需要。保存 Drive 后，配置步骤会用邮箱和密码登录。如果 MEGA 要求验证码，在这一步填写。验证码只用一次，不会保存。登录成功后，MEGA 会话保存在该 Drive 的私有数据中。之后重新加载会复用会话，直到邮箱或密码变更，或 MEGA 拒绝该会话。只有这时才填写新的验证码。

“永久删除”默认不勾选。在 go-drive 中删除或覆盖的文件会移到 MEGA 回收站，离开云盘，并可在 MEGA 自己的客户端里恢复。需要从账号中彻底移除时再勾选。此 Drive 不显示回收站。

API 连接使用 HTTPS。文件字节在传输前已经加密，因此 MEGA 建议用 HTTP 发送。网络拦截明文 HTTP 时，启用“HTTPS 传输”。此 Drive 不支持浏览器直传或直下。
